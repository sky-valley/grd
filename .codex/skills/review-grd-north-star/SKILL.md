# GRD north star

Read `docs/vision.md`; treat it as authoritative.

GRD is adaptive version control: Changes become accepted Intent through Evaluation.

Use this spine:

> Change → immutable Version → Evaluation → Requirement/Response → Promotion → Intent

Require governing-Intent authority, durable exact-Version facts, explicit Promotion, preserved provenance, adapter-neutral core, and inspectable resumable interfaces.

Flag fixed ceremony, candidate self-authorization, hidden authority, mutable history, Git-shaped semantics, and provider or caller leakage.

Do not confuse unfinished work with philosophical drift. Report blocker or debt, evidence, trade-off, and smallest correction.
